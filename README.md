# ORION GCS — інсталятори

Наземна станція для UGV на ArduPilot Rover, ESP32 і UGV Carrier v2: телеметрія, 3 камери, мапа, налаштування пультів Radiomaster, Starlink.

**Завантажити:** розділ [Releases](https://github.com/megagoldenmen-bot/orion-releases/releases/latest) → `ORION-GCS-Setup-<версія>.exe` (Windows) або `ORION-GCS-<версія>.AppImage` (Linux).

**Інструкція користувача (PDF):** [docs/ORION-GCS-Instrukcia.pdf](docs/ORION-GCS-Instrukcia.pdf) (англійською — [docs/ORION-GCS-Manual-EN.pdf](docs/ORION-GCS-Manual-EN.pdf)) — встановлення, підключення ровера, налаштування пульта, камер, параметрів і плат ESP32 зі скріншотами.

Встановлена програма сама перевіряє цей репозиторій і пропонує оновитися (розділ «Система»).
Інсталятори публікує GitHub Actions автоматично.
