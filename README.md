# ORION GCS — інсталятори

Наземна станція для UGV на ArduPilot Rover і ESP32: телеметрія, 3 камери, мапа, налаштування пультів Radiomaster, Starlink.

**Завантажити:** розділ [Releases](https://github.com/megagoldenmen-bot/orion-releases/releases/latest) → `ORION-GCS-Setup-<версія>.exe`.

**Інструкція користувача (PDF):** [docs/ORION-GCS-Instrukcia.pdf](docs/ORION-GCS-Instrukcia.pdf) — встановлення, підключення ровера, налаштування пульта, камер, параметрів і плат ESP32 зі скріншотами.

Встановлена програма сама перевіряє цей репозиторій і пропонує оновитися (розділ «Система»).
Інсталятори публікує GitHub Actions автоматично.
